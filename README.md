# Qadam — Кешкі аудан

Қалалық әңгімелік ойын — Астананың «Кешкі аудан» шағын ауданы. Godot 4.4 жазылған, интерфейс пен диалогтар қазақ тілінде. Барлық модельдер мен ассеттер Git-те, қосымша жүктеу керек емес.

## Ойын қандай

Таңғы 09:00-да аудан көшеге шығады. Күн ішінде (09:00–18:00 — 10 минут ойын уақыты):

- тапсырыстарды жеткізіп, ақша тауысасыз (700–1500 ₸);
- дүкенде ас сатып аласыз (200 ₸, ақша жетсе — қарызға);
- үйде іс-әрекет орындап, түнде ұйықтайсыз;
- көршілермен сөйлесесіз — жазу арқылы да, микрофон арқылы да.

Күн аспаны біртіндеп кешке ауысады, 23:59-да сағат тоқтайды, жаңа күн ұйықтаудан басталады.

## Іске қосу

```sh
git clone https://github.com/markhashevanazerke-sketch/qadam.git
cd qadam
./run
```

Windows: `run.bat`. Godot 4.4 орнатқан болсаңыз — `godot/project.godot` файлын ашып, **F5** басыңыз.

## LLM және API кілт (Alem)

Көршілердің жауаптарын **Alem** LLM-і жазады: `https://llm.alem.ai/v1/chat/completions`. Ойын қазір **gemma4** моделін қолданады; [plus.alem.ai](https://plus.alem.ai) сервисінде **qwen3.8**, **gemma4**, **gpt-oss** моделдері бар.

Кілт алу реті:

1. [https://plus.alem.ai](https://plus.alem.ai) сайтына кіріңіз;
2. API кілтін алыңыз;
3. Кілтті мына үшеуінің бірине салыңыз:

**А) `config/llm.cfg` файлы** — жоба папкасында, ең оңайы:

```ini
[alem]
api_key=ӘПІЙІН_КІЛТ
```

**Б) орта айнымалысы:**

```sh
export ALEM_API_KEY="ӘПІЙІН_КІЛТ"
```

**В) `user://llm.cfg`** — сол форматта (Linux-та файл: `~/.local/share/godot/app_userdata/nazerke-mini-gta/llm.cfg`).

⚠️ **API кілт репозиторийге жазылмаған** — өз кілтіңізді алып, жоғарыдағыдай салыңыз.

Кілтсіз де ойын жүреді: карта, жүріс, тапсырыстар жұмыс істейді; тек жаңа сөйлесу бастау және жұмысқа түсу LLM байланысын қажет етеді.

## Дауыс (микрофон) — қалағанда ғана

Дауысты тану мен сөйлеу **жергілікті** жүреді: Vosk Kazakh (тану) + ISSAI/Piper (синтез). Аудио желіге шықпайды, төлемді дауыс API-сі қолданылмайды.

- `./setup-voice` — дауыс қызметін орнату (Linux, Python 3.11);
- орнатпаған болсаңыз — чат тек мәтін режимінде жұмыс істейді, ойын тоқтамайды.

## Репозиторий құрылымы

```
godot/    — Godot 4.4 жобасы: код, сценалар, барлық ассеттер
voice/    — дауыс қызметі (Vosk STT + ISSAI TTS, Python)
blender/  — кейіпкерлердің Blender бастапқы файлдары
tools/    — қосымша скрипттер
media/    — демо видео
run       — Linux іске қосушы
run.bat   — Windows іске қосушы
```
